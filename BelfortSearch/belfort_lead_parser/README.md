# Belfort Lead Parser

Локальное Windows-приложение для поиска и оценки потенциальных клиентов компании Belfort, которая продаёт разработку сайтов для бизнеса.

## Состояние проекта

Реализованы Этапы 1–6 из ТЗ: каркас, логирование, SQLite-база с миграциями и бэкапом, модель лида, репозитории, скоринг 0–100, дедупликация, проверка сайтов, поиск контактов, источник CSV-импорта, оркестратор поиска, графический интерфейс (PySide6) и экспорт в Excel/CSV.

## Требования

- Windows 10/11;
- Python 3.10 или новее.

## Установка

```cmd
cd belfort_lead_parser
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## Запуск

Графический интерфейс (рекомендуется):

```cmd
python main.py
```

Консольный режим (проверка базы без окна):

```cmd
python main.py --cli
```

Тесты:

```cmd
pytest -q
```

Ожидаемый результат: все тесты проходят; логи пишутся в `logs\belfort.log` (UTF-8), база создаётся в `data\belfort.db`.

## Как пользоваться

1. Заполните «Нишу» и «Город» (например, «натяжные потолки» / «Ростов-на-Дону»).
2. Укажите целевое количество качественных лидов (по умолчанию 50).
3. Выберите CSV-файл со списком компаний — пока это единственный полностью рабочий источник без API-ключей.
   - Колонки файла: `Название`, `Город`, `Адрес`, `Телефон`, `Сайт`, `Ссылка на карточку`, `Рейтинг`, `Количество отзывов`, `Ниша` (разделитель `;` или `,`).
4. Нажмите «Начать поиск». Интерфейс не зависает: поиск идёт в фоновом потоке.
5. По ходу работы видите счётчики и статусы: найдено, проверяется, подходит, сомнительный результат, дубликат, отклонён, ошибка источника.
6. Результаты сортируются по убыванию балла; есть фильтры по статусу и минимальному баллу.
7. Экспортируйте в Excel или CSV (UTF-8 с BOM, удобно для русского Excel). Excel содержит фильтры, закреплённую шапку, кликабельные ссылки и лист со статистикой запуска.
8. История запусков и сомнительные совпадения доступны в соответствующих разделах.

## Ограничения источников (честно)

| Источник | Статус |
|----------|--------|
| Импорт CSV (пользовательский файл) | Работает полностью |
| Google Maps | Ограничение: без платного API автоматизированный сбор не реализован |
| Яндекс Карты | Ограничение: без платного API автоматизированный сбор не реализован |
| 2ГИС | Ограничение: без платного API автоматизированный сбор не реализован |

Платные подписки и ключи API не обязательны. Приложение не обходит CAPTCHA, авторизацию и лимиты запросов.

## Структура проекта

- `main.py` — точка входа (GUI или `--cli`);
- `config/settings.py` — настройки, пути, лимиты сети;
- `core/scoring.py` — скоринг 0–100 с расшифровкой;
- `core/deduplication.py` — точные и сомнительные дубли;
- `core/website_checker.py` — проверка сайта (5 статусов);
- `core/contact_finder.py` — поиск публичных деловых контактов;
- `core/search_manager.py` — оркестратор запуска поиска;
- `database/` — SQLite, репозитории, миграции, бэкап;
- `sources/` — адаптеры источников;
- `app/` — интерфейс PySide6 (окно, таблица, воркер, диалоги);
- `exporters/` — Excel и CSV;
- `utils/` — HTTP-клиент с лимитами, логирование, нормализация;
- `tests/` — автоматические тесты.

## Текущие ограничения версии 0.1

- Единственный полностью рабочий источник — импорт CSV.
- Картографические источники добавятся, когда появится разрешённый способ сбора данных без платных ключей.
- Количество качественных лидов в день зависит от источника и фильтров; цель в 50 лидов — параметр, а не гарантия.
